How to Create Your Social Sharing Image

This preview shows how your social sharing image will look. To create the actual image file:

  1. Right-click on the image above
  2. Select "Save image as..." or "Copy image"
  3. Save it as social-share-card.jpg in your public/images/ folder
  4. Or use a screenshot tool to capture just the card area

Alternative: You can also use online tools like Canva, Figma, or even this HTML file with browser developer tools to create the perfect social sharing image.
